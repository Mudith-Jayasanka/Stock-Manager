## Problem Summary
The Customers page (`/customers`) lacks a "+ Add Customer" / "+ Create Customer" action button and customer creation modal. Although the backend supports customer creation (`POST /api/customers`) and test selectors (`customers-create-btn`, `customer-name-input`, etc.) are registered in `UI_SELECTORS`, the frontend UI component (`CustomersListComponent`) and frontend service (`CustomersService`) only implement listing, editing, and deleting customer records.

## Expected Behavior
1. The Customers page header should display a primary "+ Add Customer" button tagged with `data-testid="customers-create-btn"`.
2. Clicking "+ Add Customer" opens a Create Customer modal with form inputs for Full Name (`customer-name-input`), Phone (`customer-phone-input`), Email (`customer-email-input`), and Address (`customer-address-input`).
3. Submitting valid customer details calls `CustomersService.createCustomer()`, sends a `POST /api/customers` request, prepends the new customer to the list, updates pagination, and closes the modal.
4. Validation errors (such as duplicate phone numbers from the backend 409 response) are displayed within the modal.

## Root Cause
When the Customers feature UI was originally created, only listing and searching were included. Edit and delete modals were added later, but the customer creation button and modal were omitted from `customers-list.component.html`, `customers-list.component.ts`, and `customers.service.ts`.

## Proposed Changes
- **`frontend/src/app/services/customers.service.ts`**: Add `createCustomer(payload: Omit<Customer, 'id' | 'createdAt'>): Observable<Customer>`.
- **`frontend/src/app/pages/customers/customers-list/customers-list.component.ts`**: Add modal state (`showCreateModal`), `createForm` model, `openCreate()`, `closeCreate()`, and `createCustomer()` handlers.
- **`frontend/src/app/pages/customers/customers-list/customers-list.component.html`**: Add "+ Add Customer" header button and Create Customer modal dialog with exact `data-testid` attributes matching `UI_SELECTORS.CUSTOMERS`.
- **`tests/e2e/app.spec.ts`**: Add E2E test step to create a new customer through the UI and verify list propagation.

## Verification Plan
1. API Integration Tests: Run `npm run test:api` to verify backend `POST /api/customers` behavior.
2. E2E Automated Tests: Run `npm run test:e2e` to verify Playwright E2E customer creation and table propagation.
