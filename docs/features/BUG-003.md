- **Type**: Bugfix

- **Date Completed**: 2026-08-23

## Problem Summary
When recording a material purchase on the Material Purchases page (`/purchases`), the modal dialog is excessively tall vertically (`max-width: 520px` with all 7 form sections stacked sequentially in a single column). At standard 100% browser zoom on standard laptop/desktop viewports, the top header and bottom save/cancel actions are pushed offscreen and cut off.

## Expected Behavior
1. The modal dialog should fit comfortably on screens at 100% zoom without clipping the header or action buttons.
2. The layout should utilize horizontal width more efficiently (increasing modal max-width to `720px` and organizing inputs into 2-column and 3-column rows).
3. The modal card should enforce `max-height: 90vh` with vertical scrolling (`overflow-y: auto`) on the body content to ensure accessibility on small viewports.
4. All existing form fields, validation behavior, calculations, and `data-testid` attributes must be preserved without breaking existing tests or backend contract.

## Root Cause
The `modal-card` CSS class in `purchases-list.component.scss` restricted modal width to `520px` and had no max-height constraints. The template (`purchases-list.component.html`) placed category toggles, material selection, quantity/unit, cost, unit cost preview, supplier, and notes vertically in a single column layout.

## Proposed Changes
- **`frontend/src/app/pages/purchases/purchases-list.component.html`**:
  - Reorganize form fields into horizontal grid rows:
    - **Row 1**: Category toggle buttons (Wax / Fragrance / Container).
    - **Row 2**: 2 columns for Select Material dropdown & Total Purchase Cost input.
    - **Row 3**: 3 columns for Quantity Purchased, Unit select, and Unit Cost Preview badge.
    - **Row 4**: 2 columns for Supplier Name input & Notes/Batch Info text input.
  - Retain all `data-testid` attributes (`purchases-record-btn`, `purchase-category-wax-btn`, `purchase-category-fragrance-btn`, `purchase-category-container-btn`, `purchase-material-id-select`, `purchase-quantity-input`, `purchase-unit-select`, `purchase-total-cost-input`, `purchase-supplier-input`, `purchase-notes-input`, `purchase-submit-btn`).
- **`frontend/src/app/pages/purchases/purchases-list.component.scss`**:
  - Update `.modal-card` max-width to `720px` and set `max-height: 90vh; display: flex; flex-direction: column;`.
  - Update `.modal-body` to set `overflow-y: auto; gap: 14px; padding: 20px 24px; flex: 1;`.
  - Add form row flex utility rules for multi-column grid layouts.
