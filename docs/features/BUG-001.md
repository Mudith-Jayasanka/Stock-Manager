# Bug Description: BUG-001

## Metadata
- **Ticket ID**: `BUG-001`
- **Title**: Profit badge text wrapping across multiple lines on Products page
- **Type**: Bugfix
- **Status**: Completed
- **Target Branch**: `fix/BUG-001`
- **Date Created**: 2026-08-22

## Problem Summary
On the Products page (`/products`), the profit badge splits the currency prefix ("Rs.") and the price amount onto separate lines when displayed in table rows.

## Expected Behavior
The currency prefix ("Rs.") and the numeric price value inside `.profit-badge` should remain together on a single line without wrapping.

## Root Cause
In `products-list.component.scss`, the `.profit-badge` class does not specify `white-space: nowrap` or an explicit `display: inline-block` behavior to prevent text wrapping across line breaks.

## Proposed Changes
- **File**: `frontend/src/app/pages/products/products-list/products-list.component.scss`
- Add `white-space: nowrap;` and `display: inline-block;` to `.profit-badge`.

## Verification Plan
1. Check product list rendering to verify profit badges remain strictly single line.
2. Build/test frontend component to ensure no styling regressions.
